# Niche-library / video roadmap — next ~150 job-types

The app has **55 templates** today (the video-able base). To grow video coverage toward the hundreds, expand the niche library. Each new template = a new app capability **and** a ~$2 video that powers a trade-hub page + its city/intent variants.

Priority key: **P1** = high search demand + prices cleanly today (Bunnings/count-based → make videos first). **P2** = solid demand. **P3** = long-tail. **[SL]** = needs the supplier-list feature (ticket: Refined Mate chat pipeline) before it prices credibly. **[M]** = measurement/photo-driven (benefits from the photo/floorplan prompt + #32).
