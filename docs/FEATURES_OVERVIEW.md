# QuoteMate Features Overview

QuoteMate is a professional quoting and invoicing app designed for Australian tradies. This document provides an overview of all major features.

## Core Features

### Quote Management

Create professional quotes quickly and easily.

**Key Capabilities:**
- Create quotes from scratch or templates
- Add customer details (name, email, phone, address)
- Describe job requirements
- Add materials with automatic pricing
- Configure labor hours and rates
- Apply markup percentages
- Generate professional PDF quotes
- Share via email, SMS, or WhatsApp
- Track quote status (draft, sent, accepted, rejected)
- Duplicate quotes for similar jobs
- Cloud sync across all devices

[Learn more about Quotes](./QUOTES.md)

### Invoice Management (NEW)

Convert quotes to invoices and track payments.

**Key Capabilities:**
- Create invoices from scratch
- Convert accepted quotes to invoices
- Set payment terms (Due on Receipt, Net 7/14/30, Custom)
- Track invoice status (draft, sent, paid, partial, overdue)
- Record full or partial payments
- Generate professional PDF invoices
- Include payment method details
- Automatic overdue detection
- Share via email, SMS, or WhatsApp

[Learn more about Invoices](./INVOICES.md)

### Payment Tracking (NEW)

Record and monitor payments on invoices.

**Key Capabilities:**
- Record payments with amounts and dates
- Track payment methods (bank, card, cash, cheque)
- Add payment notes for reference
- Monitor partial payments
- Calculate amounts due
- Automatic status updates

[Learn more about Payment Tracking](./PAYMENT_TRACKING.md)

## Pricing Features

### Material Pricing

Get accurate material prices from multiple sources.

**Price Sources:**
- **Bunnings API** - Direct pricing from Bunnings warehouse
- **Web Search** - Fallback pricing from online sources
- **AI Estimation** - Intelligent price estimates when other sources unavailable

**Material Management:**
- Search for materials by name
- View product details and images
- Add custom materials manually
- Save favorite materials for reuse
- Automatic quantity suggestions

### AI-Powered Suggestions

Use AI to analyze jobs and suggest materials.

**Capabilities:**
- Describe a job in plain language
- AI analyzes requirements
- Receive material suggestions with quantities
- Automatic pricing lookup
- Adjust suggestions as needed
